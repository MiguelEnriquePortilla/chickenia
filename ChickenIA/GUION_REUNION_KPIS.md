# Reunión breve con el equipo

Equipo, ya hacemos muchas cosas bien. Ahora queremos ayudarnos a que eso bueno se repita todos los días y que el esfuerzo de cada quien se vea.

Vamos a tener cuatro revisiones sencillas: a las 9:30, estar listos para abrir; a las 12, listos para la comida; a las 4, revisar cuánto falta producir para vender bien y desperdiciar menos; y a las 7, dejar el día cerrado y reportado.

Cada área tendrá una meta clara. Si algo falta, lo avisamos a tiempo y buscamos cómo resolverlo juntos. Al principio también vamos a revisar que las metas sean claras y justas.

Nuestra intención es que este trabajo nos permita implementar bonos de desempeño pronto. Este mes vamos a aprender a usar el sistema y revisar los resultados; los bonos vendrán después, con reglas que todos conozcamos.

Ayúdennos a hacer constante lo que ya hacemos bien, mejorar lo que haga falta y construir una forma de reconocer ese esfuerzo.
