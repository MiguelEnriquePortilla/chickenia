# ChickenIA workspace design

Reference: the desktop conversation interface supplied by Miguel on 2026-09-11.
Brand sources: Manual Identidad Chicanito and Extension de Identidad 2026.

## Shared interface

- `css/refined.css` is loaded last on the five application entry points.
- Light: white working canvas, warm quiet sidebar. Dark: charcoal with a subtle navy tone.
- Brand red #E30613, navy #1A213E, cream #FFF6EB and gold #D9A441 remain the identity palette.
- System sans-serif for working UI; original wordmark and original vector logo for identity.
- `js/area-navigation.js` owns grouped navigation and area context. Inventory owns permission filtering.
- `js/refined.js` provides the same theme control and account/actions menu, preserving existing action handlers.
- Inventory links retain area and tab context. Navigation collapses on small screens.
- Landing watermark uses the supplied original vector artwork; texture is generated by SVG turbulence.
- Operational data, APIs, authentication and database schemas are unchanged.

## Validation

Run the existing Node test suite and `python test/inventory_browser.py`.
Run `python test/refined_browser.py` for light/dark, desktop/mobile, navigation, dashboard controls and chat.
The latter uses explicit dashboard API fixtures and a disposable local database for login and chat.
Neither browser suite writes production data.

## Release

`node scripts/build-static.js` assembles the public allowlist.
Push the reviewed commit to main in the existing GitHub repository. Vercel publishes chickenia.chicanito.app.
Verify the deployed HTML and new CSS/JS match the local assets before reporting completion.
